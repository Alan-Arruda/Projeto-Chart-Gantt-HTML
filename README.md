# Projeto Chart Gantt em HTML

Este projeto é um **Gráfico de Gantt** desenvolvido em **HTML, CSS e JavaScript**, pensado para visualização de cronogramas de forma simples e interativa.

## 🚀 Demonstração
Acesse o projeto publicado no GitHub Pages:  
[Projeto Chart Gantt HTML](https://alan-arruda.github.io/Projeto-Chart-Gantt-HTML/)

## 🛠️ Tecnologias utilizadas
- **HTML5** para a estrutura
- **CSS3** para o estilo e layout
- **JavaScript** para a lógica e interatividade

## 📂 Estrutura do projeto
- `index.html` → Página principal
- `style.css` → Estilos visuais
- `script.js` → Funções e interatividade

## 📌 Funcionalidades
- Visualização de tarefas em formato de gráfico de Gantt
- Organização de prazos e etapas
- Interface simples e responsiva

## 📖 Como usar
1. Clone este repositório:
   ```bash
   git clone https://github.com/Alan-Arruda/Projeto-Chart-Gantt-HTML.git
2. Abra o arquivo index.html no navegador.
3. Explore e personalize conforme sua necessidade.
4. OBS.: O projeto ainda está passando por atualizações, pretendo inserir Recursos e Custos!
